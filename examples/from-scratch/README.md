# A derivation from blank canvas

This example constructs nodes and edge ports from entity records using the geometry
helpers. It deliberately does not select a layout. Run `node scripts/build-examples.mjs`.

Change `cols:3` to a vertical arrangement only after recomputing height, node content,
edge ports and title/caption rails. Keep node IDs and edge direction. Inspect long
labels before adding more nodes. The example demonstrates how to construct a new
composition, not a required visual pattern.
